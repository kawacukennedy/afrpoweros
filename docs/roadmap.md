# Roadmap

AfrPowerOS is community-built and early-stage. Priorities below; they move with
contributor interest and real-world events.

## Phase 1 — Foundation (in progress)

- [x] Repository skeleton, governance, CI, validator.
- [x] Dataset v0.1: 11 countries (Rwanda, Kenya, Ghana, Egypt, South Africa,
      Uganda, Tanzania, Nigeria, Zambia, Morocco, Algeria).
- [ ] Coverage of all African countries with any nuclear/energy program
      (target: every IAEA member state with a program; explicit `None` entries
      for the rest of the continent).
- [ ] Publish a release (v0.1.0) with tagged dataset snapshot + DOI-friendly
      CITATION.cff.

## Phase 2 — Readiness tracker

- [ ] Per-country **IAEA 19 infrastructure issues** tracker (milestones/
      conditions: legal framework, regulatory body, site, funding, fuel, etc.).
- [ ] Research-reactor registry for the continent (operator, type, status).
- [ ] Event timeline view per country (driven by `key_events`).

## Phase 3 — Product surface

- [ ] Static web map (GitHub Pages / Netlify): countries colored by program
      status, click-through to records.
- [ ] Programmatic API (read-only) over the dataset.
- [ ] Weekly refresh workflow that re-verifies `last_verified` ages and flags
      stale records.
- [ ] Newsletter / digest (Vol 0: "Nuclear Africa — the brief").

## Phase 4 — Community & scale

- [ ] Contributor guide in three languages (EN, FR, AR).
- [ ] Student/early-career contribution program (African university outreach).
- [ ] Institutional partnerships (energy ministries, agencies, research
      institutes) for correction loops and primary-source feeds.
- [ ] Paid B2B layer (reports, alerts, custom dashboards) to fund the open
      dataset — the open dataset stays free, CC BY 4.0, forever.

## How to help

Pick anything in this list. Every contribution must follow
`CONTRIBUTING.md` and the methodology. Start with one country correction or
one new country — that is genuinely the most valuable work.
